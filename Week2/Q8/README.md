# 問8｜ゴルーチン（Goroutine）基礎

## 目標
Go言語最大の強みである軽量スレッド「ゴルーチン（Goroutine）」の基本的な起動方法と、並行処理の挙動を理解します。

## 今回の演習で学ぶこと
この問題では、「仕事を同時並行でやらせる」ゴルーチンの基本を学びます。

---

### なぜ並行処理が必要か？　〜 直列処理の問題点

Web アプリケーションで「ユーザー情報の取得」「注文履歴の取得」「在庫確認」を順番に実行するとします：

```
ユーザー取得（100ms）→ 注文履歴（200ms）→ 在庫確認（150ms）
合計: 450ms
```

これらが**互いに依存していない**なら、同時に動かせば：

```
ユーザー取得（100ms）─┐
注文履歴（200ms）─────┤→ 全完了: 200ms（最も遅いものの時間だけ！）
在庫確認（150ms）─────┘
```

**約2倍以上速くなります。**　これが並行処理の力です。

---

**1. なぜ並行処理が必要か**

ファイルの読み込み・ネットワーク通信・重い計算などが複数あるとき、順番に1つずつ実行するとすべての完了を待ち続けることになりプログラムが遅くなります。ゴルーチンを使うと、複数の処理を「同時に」走らせることができます。

---

**2. ゴルーチンの起動**

関数の呼び出しの前に `go` をつけるだけです。たったこれだけです！

```go
// 通常の呼び出し（同期）
doWork()    // doWork が終わるまで次の行に進まない

// ゴルーチンとして起動（非同期）
go doWork() // すぐ次の行へ進み、doWork はバックグラウンドで動く
```

「バックグラウンドで動く」とはどういうことでしょうか？具体例で見てみましょう：

```go
func Count(name string) {
    for i := 1; i <= 3; i++ {
        fmt.Printf("%s: %d\n", name, i)
        time.Sleep(100 * time.Millisecond)
    }
}

func main() {
    go Count("A")  // バックグラウンドで動く
    Count("B")     // こちらが完了するまで待つ
}
// 出力例: A:1 B:1 A:2 B:2 A:3 B:3 （入り混じる！）
```

---

**3. 注意：メイン関数が終わるとゴルーチンも終わる**

`main` 関数が終了するとプログラム全体が終了し、ゴルーチンも強制終了されます。そのため、ゴルーチンが動く時間を確保するために `time.Sleep` などで待機します（正式には次の問題で学ぶ `sync.WaitGroup` を使います）。

```go
go doWork()
time.Sleep(1 * time.Second) // ゴルーチンが動く時間を確保
// この方法は「だいたい1秒あれば終わる」という前提なので、あまりよくない
```

> **なぜ `time.Sleep` は理想的でないのか？** 処理時間が正確にわからないので、遅すぎると無駄に待ち、短すぎると処理が途中で切れます。Q9で学ぶ `WaitGroup` がより正確な方法です。

---

**4. ゴルーチンは「軽量」**

一般的なOSスレッド（Java の Thread など）と比べると、ゴルーチンは非常に軽量です：

| | OSスレッド | Goのゴルーチン |
|--|----------|----------------|
| 初期スタックサイズ | 〜1MB | 〜2KB（500倍以上軽い！）|
| 作れる数（目安） | 数千 | 数十万〜数百万 |
| コンテキストスイッチコスト | 高い | 非常に低い |
| 管理 | OS が管理 | Go ランタイムが管理 |

---

## 問題文
`main.go` の `___` の部分を埋めてプログラムを完成させてください。

1. `Count(name string)` 関数は1から3の数字を出力します。
2. `main` 関数で `Count("A")` を**ゴルーチンとして**（非同期に）呼び出してください。
3. `Count("B")` を**通常の関数として**（同期的に）呼び出してください。
4. 出力の順番がA・Bで入り混じることがあることを確認してください。

### 実行方法
```bash
cd /project/workspace/Week2/Q8
go run main.go
```

### テストでの確認
```bash
cd /project/workspace/Week2/Q8
go test main.go main_test.go
```
## ヒント
- ゴルーチン起動：`go 関数名(引数)`
- `time.Sleep(time.Second)` でゴルーチンの実行を待てる
- A と B の出力順は実行のたびに変わる場合がある（これが並行処理の特徴）
- `go` をつけずに呼ぶのが「同期」、つけるのが「非同期（並行）」
